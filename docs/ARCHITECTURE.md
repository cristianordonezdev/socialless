# Architecture

- **Composition:** `SocialLessApp` opens `AppContainer`, injecting a session repository, settings repository and time source. A storage-open failure shows a recoverable error; it never deletes or silently replaces the store.
- **Domain:** Codable platform/intent/summary/checkpoint/settings models; `SessionEngine` coordinates the clock and storage behind MainActor protocols. SwiftUI observes native Observation state.
- **Clock:** `ContinuousClock`-relative durations, accumulated active segments. Wall time supplies human-readable timestamps only. A 200ms UI task refreshes state; it is not the source of elapsed time.
- **State:** idle → active ↔ paused → completed. Warning derives from `0 < remaining <= 60`. Closing at/after the deadline records expiry. Completed state is set synchronously before persistence; repeat finish events are no-ops.
- **Persistence:** SwiftData stores encoded metadata in two models: completed records and a single active checkpoint. UUID uniqueness plus existing-ID checking provides idempotence. Finish and checkpoint removal share a context save; failures roll back. Autosave is disabled to avoid partial mutations.
- **Recovery:** startup finalizes only the checkpoint’s measured duration. Live state is never resumed after a process restart. Local history opt-out avoids writing both completed records and checkpoints.
- **Settings:** versioned Codable payload in app-only UserDefaults. Invalid duration preferences fall back to 10 minutes. Corrupt payloads are reported, not overwritten.
- **UI:** native onboarding, dashboard, full-screen intentional session flow, insights, settings and privacy. The full-screen flow owns a cancellable ticker. The root observes scene activation for timing.
- **Browser:** one `WKWebView` per session. A controller owns security delegates and display state; a representable owns placement only. Disappearance disables interaction/media and stops loading. Completion removes the host; delegates also consult live session state before navigation.
- **Demo:** app-bundled HTML via `loadHTMLString`, nonpersistent WebKit store, restrictive CSP, no scripts/forms/network resources. Only its initial `about:blank` document navigation is allowed.
- **Website:** ordinary WebKit store; standard platform home only. HTTPS and exact root / dot-delimited subdomains of the selected service. No credentials in URLs, nondefault ports, HTTP, file URLs, custom schemes, external origins or new-window launch. Download requests and unsupported main-document MIME types are rejected. Exact `about:blank` / `about:srcdoc` documents are allowed only inside child frames of the hosted website; top-level policy is unchanged. Disallowed subframes are canceled without hiding the main page. Unsupported top-level links/new windows show a dismissible notice when a page has already committed; an initial blocked navigation still shows a recoverable error. Process termination clears the committed-page state. No user-agent spoofing, remote scripts or JavaScript content extraction.
- **Filters:** versioned platform/mode catalogs, strict path and rule-kind validation, opt-in demo preferences with backward-compatible decoding. A session-owned `WebFilterController` installs a bundled script in a named `WKContentWorld`, main frame only. A 300ms observer updates scoped navigation markers; disabling removes only app-owned markers/styles. Native URL observation rechecks SPA auth routes. No content, URLs or diagnostics are persisted. Instagram's exact-destination pilot starts off and requires a one-shot visible-link check before explicit enable. After an active trial, a separate Remember opt-in saves master/per-rule choices, additional-rule consent IDs and the bundled catalog version. Matching consent permits automatic checking of visible controls in each document/mutation pass; missing or partially recognized controls remain unmodified per rule. Explore is independently checked through a read-only probe that preserves the active runtime, starts off, and requires separate consent; search subpaths are excluded. Readiness is always temporary, old catalog consent is rejected, and forgetting restores session-only behavior. Facebook/TikTok website catalogs remain empty. See `FILTERS.md`.
- **Tests:** hosted XCTest tests for domain/persistence/security, plus XCUITest flows. Debug-only UI launch flags use a separate preferences suite/store. Reset flags cannot touch normal user data. The Instagram UI fixture uses fictional in-memory HTML, a restrictive CSP and an ephemeral WebKit store; its two required flags and fixture compile out of Release.

Instagram's 0.3.0 catalog constrains its two dedicated rule kinds to the website's exact Reels and Explore destinations; Explore is off by default and independently gated. It recognizes semantic navigation or a fixed accessibility label on the anchor/SVG, with the existing protected-context exclusions. Only enum states and bounded counts leave WebKit. Unknown controls remain visible and are reflected in unsupported/partial health; CSS conflicts fail open. Mutation observation also reconciles site edits to labels, visibility/styles and the owned marker without observing the app's own writes.

## Deliberate limits

No friends detector, default-enabled website filters, verified friends/following destinations, OAuth exceptions, Screen Time frameworks, extensions or server. Website subresource traffic remains controlled by WebKit and the provider; the navigation allowlist is not advertised as a network content blocker. Native-app and Safari time is not measured.

The V0.1 data set is small; the idempotence check currently scans record IDs on completion to avoid an SDK predicate-concurrency diagnostic. It does not deserialize social content (none is stored). Add an indexed fetch when large histories warrant it and the supported toolchain passes the predicate check cleanly.



### Imported following snapshot and feed runtime

`FollowingListImporter` parses bounded user-selected JSON off the main actor, returning only normalized unique handles and an import date. `FollowingListStore` owns the reviewed snapshot through an injected repository; production uses `FileFollowingListRepository` with atomic complete file protection and a backup-excluded directory. Existing settings, session records and WebKit sign-in remain separate. A failed read/write does not clear existing data. File security scope is released after import; the source URL/file is not retained.

`BrowserController` creates `FollowingFeedController` only for Instagram website sessions. It uses a separate content world/message handler and observes document/SPA lifecycle, independent of navigation catalog scripts. The snapshot is supplied from AppContainer; activation is session memory only. A changed/deleted snapshot turns the filter off, and shutdown makes late operations inert. `following_feed.js` performs bounded semantic author matching in the home feed, with reversible markers, throttled mutations and fail-open behavior. Website author identities remain within the WebKit evaluation; only bounded counts and enum health return to native UI. See ADR-016 for the explicit user-authorized extension to the original privacy scope.
