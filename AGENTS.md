# SocialLess contributor contract

- Read `SOCIALLESS_CODEX_MASTER_SPEC.md` and `docs/IMPLEMENTATION_STATUS.md` first.
- Native SwiftUI, iPhone / iOS 17+, no third-party runtime dependencies.
- Product copy is English. Keep privacy and availability claims honest.
- Never collect website credentials, cookies, content, or URLs in logs/storage.
- Demo mode must work without internet, accounts, or permission prompts.
- Use injected monotonic time and repositories. Test lifecycle and terminal states.
- All website integrations remain experimental until documented physical-device QA.
- No Screen Time target/entitlements until Phase 5 prerequisites are met.
- Run `python3 scripts/generate_project.py` when adding/removing source/resources.
- Build and run relevant tests; record actual results and remaining gates in docs.
- Never replace the user's source spec or silently erase existing local data.
