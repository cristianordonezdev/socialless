# Accessibility smoke review

Date: 2026-11-09. Device: iPhone 18 Pro Simulator, iOS 27.0. This is not a complete accessibility audit.

## Inspected

- Light appearance: onboarding, dashboard, offline browser, completion. Native system typography and adaptive cards/accents; browser sample is explicitly fictional.
- Dark appearance: actual dashboard screenshot inspected after switching the simulator appearance. Adaptive background/cards and mint accent remain legible. `docs/screenshots/dashboard-dark.png` shows preferences retained from the switch-persistence test (Instagram disabled).
- Maximum accessibility content size (`UICTContentSizeCategoryAccessibilityXXXL`): dashboard wraps and scrolls; session setup’s Start and Cancel remain reachable. XCUITest exercises these controls.
- Landscape with maximum accessibility content size: platform cards remain available in a scroll view; content stays within a centered maximum width. The test restores portrait.
- Actual WebKit accessibility tree: sample heading, paragraphs and content are available. Decorative sample illustration has an accessible description; avatar initials are hidden.
- Timer has a distinct accessible label/value and stable test ID; it is not a continuously announced live region.
- Completion heading receives accessibility focus. The 60-second transition posts one announcement. Physical VoiceOver behavior remains to be validated.
- Chart has equivalent per-day text rows. Availability always uses visible words, not color alone.
- Decorative platform symbols use fixed sizing so they do not overflow their icon container at large text sizes.
- No custom motion or confetti; no reliance on animation for state changes.

## Pending

Screenshots are generated by XCTest, not design mockups. Test captures with three-second sessions use a Debug-only accelerated duration; normal user choices remain 5/10/15/20/30 minutes.
